# 三轮客户体验优化 · 2026-09-12

本轮召集 5 位 gpt-5.6-luna 子代理，分别审阅客户价值、手机体验、信息设计、数据可信度、功能可靠性。受并发限制分批执行；主代理负责集成和浏览器验收。每位均参与初审及后续复核。

## 第一轮：入口与层级

- 首页用本期具体采购任务引导；行动先于补充观察，完整研究保留在后层。
- 异地挂牌参考明确发货地及非成都到店价；来源检查部分失败、记录超时与正常状态区分。
- 手机五个主导航同时可见，角色切换固定且点击区 44px；修正首次实现的桌面双标签回归。
- 完整资料改为按需加载；首页业务数据从 2,252,261 降至 40,821 字节（未压缩，监测数据另计）。

## 第二轮：完成一条真实操作

- 采购工具绑定三款重点商品，解释三款商品与四条观察的数量口径；货款始终由本次询价填写，未知费用不默认免费。
- 草稿按商品存本设备；单位、数量、税运口径显式输入，支持成本、价差及毛利测算和导出。
- 门店页支持 50 项现场采价：保存、编辑、刷新恢复、删除撤销和回收 CSV；促销条件与证据必填规则按场景校验。
- 补齐对话框名称、打开焦点、Escape / 遮罩关闭及返回触发点；保存角色与配额偏好。

## 第三轮：收紧误解和操作边界

- 重点商品最小零售单位锁定为瓶；比较需要供货商、有效期、两份凭证、同商品/单位/税务/成都配送确认。缺比较资料仍可算基础成本。
- 结果及 CSV 标明用户填写、未独立核验。负价差和负毛利按数值导出，防止公式文本注入。
- 选填比较区折叠，采价列表直接展示促销条件和证据编号，修正过大的移动锚点间距。
- 监测计划与近 24 小时实际轮次分开展示；每来源成功年龄、连续失败、历史快照和来源日期独立提示。
- 监测 JSON 与精选线索刷新失败分别处理；精选超过 7 天提示旧观察，后台刷新不重绘正在操作的页面。

## 验证

- 10 项采集器既有测试通过。
- 成本计算、未知费用、非法数量、过期报价、凭证门槛、促销条件、未来采价时间、CSV 数值/公式处理测试通过。
- 模拟大资料请求失败后重试：核心记录保留、当前表单不重绘、并发去重、无重复记录。
- 浏览器完成：选 SKU 核价、凭证缺失阻断价差、补齐后比较、测算导出；采价促销条件拦截、保存、刷新恢复编辑、修改、删除、撤销与导出。
- 完整资料 1,489 条观察、118 份报告可访问；报告 Escape 关闭后焦点回原按钮。
- 手机 360px 九个页面整体均无横向溢出，五项导航可见；390px 采购页与 44px 角色按钮、1440px 桌面首页与导航回归检查通过。

## 保留的产品边界

这是公开情报与本设备工作工具，没有后台同步、POS、真实销量或集团任务回收服务。资料检索的全部筛选条件暂未编码进可分享 URL；旧报告表格在手机保留可横滑表格并提示、冻结首列。上述不阻断本轮工作流程，不包装成已提供的能力。
