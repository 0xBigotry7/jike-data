# 高密度总览恢复

首页恢复六项真实统计、全品类联动、可搜索价格观察、五家竞对研究矩阵、成都供应线索、AI 复核与采集运行。完整库加载前不显示局部总量。记录不等于独立 SKU；日期缺失不再被排到最新日期前。

手机保留三列指标、固定商品列的横向表格和 AI 复核快捷入口。AI 任务保留证据展开、成本核算与本设备待办。

## Lieflat Charts 调研

2026-09-13 阅读官方 SKILL.md、catalog.md、Basics gallery、mono-tokens.js 和 LICENSE。候选：L2 点阵排名适合可数单位但长中文分类难读；F5 横向刻度适合分类覆盖，但默认仅八行；F13 适合两层面积构成但需要层级及图表依赖。当前十五个研究分类继续使用已有独立横条图，补充范围与全分类显示。价格混有箱/瓶、不同地区和日期，暂不画汇总价格分布。只有八次不等间隔运行，继续展示逐次状态，不画假增长趋势。

官方当前 LICENSE 是 PolyForm Noncommercial 1.0.0，本项目为商业客户展示，因此未集成该 skill 的模板、token、字体或动画实现，也未安装到全局技能目录。仅调研其适用性；如取得明确商业授权再评估模板集成。现有图表代码独立于其模板。
